## 스프린트 운영 규칙

1. 스프린트 시작: 목표와 완료 정의를 다시 읽고 할 일 목록 작성 (30분)
2. 매 작업 세션 끝: experiment_log에 한 줄이라도 기록
3. 스프린트 종료: 회고 한 단락 (효과 있었던 것 / 없었던 것 / 다음 스프린트 조정)
4. 완료 정의 미달 시: 다음 스프린트로 이월하되, 스프린트 4 범위(선택 기능)를 먼저 줄인다
5. 범위 추가 요청은 01 문서 변경 이력에 적고 다음 스프린트에 반영. 현재 스프린트에 끼워 넣지 않는다
